# GAMLB — рабочая административная панель

## Рабочие разделы
- Dashboard: реальные показатели, последние пользователи и статус PostgreSQL.
- Пользователи: поиск, фильтр, роли, блокировка / разблокировка, защита от блокировки или снятия собственной admin-роли.
- Семейные деревья: загрузка реальных данных из PostgreSQL, владелец, число персон, дата создания и смена видимости (`private`, `tree_members`, `public`).
- Модерация: очередь обращений, смена статуса (`new`, `reviewing`, `resolved`, `rejected`).
- Журнал действий: отображение фактических записей.
- Настройки: технические параметры окружения.

Все изменения пользователей, видимости дерева и статуса обращения записываются в `ADMIN_AUDIT_FILE`.

## Файлы модерации
По умолчанию обращения хранятся в `./data/moderation-reports.json`. Путь задаётся переменной `ADMIN_REPORTS_FILE`.

Пример одной записи:
```json
{
  "id": "report-001",
  "reason": "Нарушение правил",
  "targetType": "person",
  "targetId": "uuid-объекта",
  "reporterName": "Имя пользователя",
  "status": "new",
  "createdAt": "2026-08-02T12:00:00.000Z"
}
```

## Проверки
- `npm run build` для frontend — успешно.
- API: вход admin, список и смена статуса обращения, запись в аудит — успешно.

Production не менялся. В архив не включены `.env`, секреты, `node_modules`, `dist` и `.git`.
